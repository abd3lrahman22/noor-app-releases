# نور — تحديثات تطبيق أندرويد

الريبو ده فيه بس ملف `update.json` وملفات الـ APK في **Releases**.
تطبيق نور بيقرا `update.json` مرة في اليوم، ولو فيه إصدار أحدث بيعرض "فيه إصدار جديد" في الإعدادات.

- آخر إصدار: صفحة [Releases](../../releases/latest)
- التثبيت: نزّل ملف `Noor-x.y.z.apk` من الموبايل وافتحه (اسمح بالتثبيت من المصدر ده لو طلب).
